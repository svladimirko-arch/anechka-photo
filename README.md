# Анечка Дмитриева — семейный фотограф в Братске

Одностраничный лендинг: HTML5 + CSS3 + Vanilla JS, без сборки.

## Запуск

**Самый простой способ** — двойной клик по файлу `Запустить сайт.bat`
(лежит рядом с папкой `site/`): он сам поднимет сервер и открёт браузер
на `http://127.0.0.1:8000/`. Окно консоли можно свернуть; закроете окно —
сервер остановится.

Вручную:

```bash
cd site
python -m http.server 8000
# открыть http://127.0.0.1:8000/
```

Через сервер сайт грузится чуть быстрее, но и двойной клик по `index.html`
теперь показывает всё, включая 3D-вихрь портфолио: если ES-модуль Three.js
не грузится (file://), виджет автоматически берёт классическую сборку
`vendor/leaf-carousel/libs/three.classic.js`. Статичная сетка остаётся
только при полном отсутствии WebGL.

## Структура

```
site/
  index.html               — разметка всех блоков
  css/style.css            — тема (палитра в :root в начале файла)
  js/main.js               — меню, параллакс, слайдер акций, форма, карусель
  assets/img/              — фото Анечки (anechka.jpg) и сертификат (certificate.jpg)
  vendor/leaf-carousel/    — готовый блок портфолио «осенний вихрь»
                             (виджет + Three.js/GSAP + листья с фото)
```

## Что заменить перед публикацией

| Что | Где |
|---|---|
| Стаж «более 5 лет» | `index.html`, блок «Обо мне» (закомментировано) и подпись в списке плюсов |
| Фон hero | `site/assets/img/hero-bg.png` (сейчас — фото 444 из `information`). Замена — подменить файл |
| E-mail | `index.html`, футер (сейчас плейсхолдер `hello@anechka-photo.ru`) |
| Цены | `index.html`, блок «Прайс» |
| Отправка формы | `js/main.js`, обработчик `submit` (сейчас демо-режим; место для fetch помечено) |
| Фото в портфолио | `vendor/leaf-carousel/assets/leaves/` — `leaf-NN.png` (лист с фото) и `leaf-NN(1).jpg` (оригинал для лайтбокса) |

## Примечания

- По всему сайту летают редкие полупрозрачные осенние листья — слой
  `js/leaves.js` (canvas, `pointer-events: none`, под шапкой и лайтбоксом).
  Настройка количества/прозрачности — константы в начале файла `makeLeaf`
  (count в `seed()`, alpha). Отключается при `prefers-reduced-motion`.
- Кнопка «Выбрать» на карточке прайса подставляет услугу в сообщение формы
  и прокручивает к контактам.
- Слайдер акций автопрокручивается (пауза при наведении), поддерживает свайп.
- Анимации отключаются при `prefers-reduced-motion`; без WebGL портфолио
  показывается статичной сеткой.
